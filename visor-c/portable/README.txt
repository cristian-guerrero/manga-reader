Manga Viewer - Portable Build
==============================

This is a portable version of Manga Viewer that can run on any Windows PC
without requiring installation of dependencies.

Usage:
------
Simply run MangaViewer.exe to start the application.

You can also drag and drop a folder with images onto the executable.

Supported Formats:
------------------
PNG, JPG, AVIF, WebP, HEIC, HEIF, JXL, TIFF, BMP and more.

Configuration:
---------------
Settings are saved in: %APPDATA%\.manga-visor\config.ini

Requirements:
-------------
- Windows 7 or later
- No additional dependencies required

Version: 1.0.0
